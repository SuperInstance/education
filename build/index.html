Your first agent, in four steps

Enough to be real. Not enough to be a tutorial that runs once and never again.

1 · Implement two methods

impl Agent for Echo {
    fn receive(&mut self, b: Bottle) -> Bottle {{ b }}
    fn inspect(&self) -> AgentState {{ AgentState::Active }}
}}

2 · Conserve on every interaction

let c = self.gamma + incoming.gamma;   // Z₃ residue
if c < -1 || c > 1 {{ return Err(Refusal::Conservation) }}
self.gamma = c;

3 · Wrap the payload so a router never decodes it

Bottle {{ routing: json!(dest, kind), payload: msgpack(encode(inner)) }}

4 · Check the witness, not the prose

fnv1a_64("café Δ 日本語") == 0x024a555471370b18d   // if this fails, stop
