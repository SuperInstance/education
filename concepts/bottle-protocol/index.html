The bottle: envelope outside, payload inside

A router must decide where a message goes without reading what it says. The bottle is how those two requirements stop fighting.

Anatomy

struct Bottle {
    routing: RoutingEnvelope,   // JSON. A router reads only this.
    payload: Vec<u8>,          // msgpack. Only the target decodes this.
}

The split is the whole idea. Routing cost stays proportional to the envelope, not the message, so a router can be a fast dumb shim and the expensive decoding happens exactly once, at the destination.

Hybrid routing

Round trip

let b = Bottle::routing(env).payload(encoded);
// a router that never decodes the payload can still route it
assert_eq!(route(&b.routing), dest);
assert_eq!(decode(&b.payload), original);
