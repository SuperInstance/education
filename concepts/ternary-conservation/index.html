Concept 1 of 6

Ternary conservation: γ + η = C

Two things meet and something is conserved. That is the whole physics of the substrate, and this page lets you break it on purpose.

The equation

Every cell in the fleet moves between three states, and every interaction between two cells conserves a quantity. Written as γ (a cell's own state) against η (the state arriving in a bottle), the remainder is C.

// the entire conservation check
fn conserve(gamma: Ternary, eta: Ternary) -> C {
    gamma + eta                     // {-1,0,+1} arithmetic, C is the residue
}

Not a metaphor for a check that happens elsewhere — it is the check, and it runs in the kernel, in every language the kernel ports to.

Classification

Any state reduces to one of three. A state that does not reduce is not a state.

Why it matters

The gauge principle

γ and η are each only defined up to a shift. C is the part that survives the shift. That is why a cell's internal representation can change without anything downstream noticing — the interface is the invariant, exactly as in electromagnetism.

Structural isomorphism to Gauss's law

Flux in, divergence out, a conserved residue. The map is exact enough to be useful and loose enough to be dangerous, which is the standing criticism — the conservation law page is where that gets taken seriously.
