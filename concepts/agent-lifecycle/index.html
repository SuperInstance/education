Concept 3 of 6

Two methods, four states, no exceptions

An agent can receive and inspect. That is the entire interface, and the entire discipline is in not adding a third.

trait Agent {
    fn receive(&mut self, bottle: Bottle) -> Bottle;
    fn inspect(&self) -> AgentState;
}

No tick, no step, no scheduler callback. An agent that does not receive is unchanged; an agent's time advances only when a bottle arrives. That is what makes the lifecycle replayable — the same bottle sequence always produces the same states, which is the property the witness chain depends on.
