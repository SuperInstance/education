Six concepts

What the substrate is actually made of

Not a product page. Each one below has a page that teaches it, and where the maths is small enough to put in the browser, it runs in the browser.

Foundational first

#ConceptOne sentence
1Ternary conservation Every interaction conserves γ + η = C, and a sum outside the range is a refusal.live calculator
2Bottle protocol A JSON envelope a router can read, wrapping a payload only the target decodes.
3Agent lifecycle Two methods, four states, and every transition is itself a bottle.

Derived

#ConceptOne sentence
4Self-improving harness Build → fail → extract pattern → vectorize → retrieve on the next failure.
5Conservation law What γ + η = C is isomorphic to in Z₃, and what the analogy buys and costs.
6Wavelet decomposition Signals read by scale, in the order the scale changes.

Dependency order

ternary conservation
   └─> bottle protocol        (a bottle is where γ meets η)
        └─> agent lifecycle    (states move; each move is a bottle)
             ├─> harness         (failures become retrievable patterns)
             └─> conservation law (the Z₃ isomorphism, taken seriously)

Read in that order and the later pages make sense on their own terms. Read out of order and every one of them looks like a riddle.
